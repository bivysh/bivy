The canonical, de-duplicated component set — one version of each pattern. Toggle theme to check light + dark.

Every value below comes from packages/ui/tokens.css — the single source of truth. App CSS references tokens with var(--…) and never hardcodes a color or size. Each component is the one canonical pattern; the “Consolidates” note lists the many bespoke classes in packages/web/src/styles.css that should converge onto it. Run pnpm run check:design before finishing UI work.

Radius & elevation
Pick from the radius scale (--radius-sm 8 / -md 12 / -lg 16 / -xl 20 / -full). The app currently uses 8/10/12/14/16/18px ad-hoc — standardize on the scale.

Buttons

One .btn with variant + size modifiers. There should be no bespoke accent-filled button.

Variants .btn / .primary / .ghost / .danger / .danger-ghost / .link
Consolidates: .notice-action, .trial-wall-cta, .banner-action, .fork-submit, .import-session-action, .autom-new-btn, .ghost-btn, .link-btn, .icon-btn — all re-implement .btn.primary/.ghost. Use one on-fill text color (--accent-contrast), not a mix of white/#fff.

Badges

One .badge, colored by data-tone and styled by data-variant (outline / soft / solid). A status is shown once, one way.

Outline data-variant="outline" (default)
neutral accent passed warning failed merged unseen
Soft & solid data-variant="soft" | "solid"
accent success warn error critical new 3
Consolidates FOUR overlapping systems: outline pills (.chip, .chk, .runtime-*, .github-pill, .session-pr), uppercase soft/solid badges (.approval-badge, .question-chip, .artifact-badge, .tool-fail, .session-filter-count), and info pills. Note the app spelled “warning” three ways (--accent vs --warn) — here it's always --warn.
