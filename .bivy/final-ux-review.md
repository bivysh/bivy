# Final UX review

Blockers found against `docs/key-vault-product-review.md`:

- **High — First-use flow exposes advanced concepts and can lose the automatic default.** `packages/web/src/components/CredentialVault.tsx:251-265` always asks a first-time Anthropic/OpenAI user for a name and machine/device availability, contrary to the first acceptance criterion. A supplied first name becomes the storage label (`:116`) without creating the provider-default assignment; the detail then reports it is not the default (`:276`). Adding another named item can therefore leave the provider ambiguous instead of keeping the first credential as the default.
- **High — Multiple OAuth accounts cannot satisfy the naming/assignment criterion.** The name control is hidden whenever OAuth is selected (`packages/web/src/components/CredentialVault.tsx:251-257`), and OAuth is started with only a provider ID (`:140-144`). There is no way to create a named second subscription credential for one provider, so it cannot subsequently be assigned.
- **High — Device-only custody is described incorrectly.** In machine availability, every offline machine says “Will sync when online,” including for a device-only credential (`packages/web/src/components/CredentialVault.tsx:321`). This directly contradicts “Only this device” and prevents users from reliably answering where the credential can be used.
- **High — The add flow ignores the catalog’s declared auth methods.** `packages/core/src/provider-catalog.ts:49` declares `openai-codex` as OAuth-only, but `packages/web/src/components/CredentialVault.tsx:246-249` always offers API key and password-manager methods. Users can save an unusable credential under the ChatGPT-subscription provider identity.
- **Medium — Form semantics block assistive-technology users.** Visible labels are not associated with their inputs/selects (`packages/web/src/components/CredentialVault.tsx:231-265,307-311`), and the sign-in-method buttons expose selected state only through styling, with no radio/pressed semantics (`:245-250`). Screen-reader users cannot reliably identify controls or the active method (WCAG 1.3.1 / 4.1.2).
