# Code of Conduct

Bivy follows the Contributor Covenant Code of Conduct, version 2.1.

Be respectful, constructive, and welcoming. Harassment, abuse, discrimination, and sustained disruptive behavior are not acceptable.

Instances of unacceptable behavior can be reported to the project maintainer at `conduct@bivy.sh`. Reports will be reviewed and handled in good faith, and the reporter's privacy will be respected.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
